# Lista del Super

**App:** https://guardvalker.github.io/lista-super/

Lista de compras para el supermercado, organizada por categorías, con
sincronización entre dispositivos, recetas, menú semanal y precios de
referencia actualizados periódicamente por scrapers propios.

PWA de un solo `index.html` (HTML/CSS/JS vanilla, sin build step), instalable
en el celular. Backend en el proyecto Supabase compartido `bonapps`.
